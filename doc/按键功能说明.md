# 按键与板载指示 功能说明（V34 旋转转场版）

工程：`zuizhong_V26`　器件：安路 EG4S20BG256　工具链：Anlogic TD5.6.2

---

## 一、按键总表

核心板为 **4×4 矩阵键盘**。本设计用 **Row0 / Row1 两行 × Col0~Col3 四列**，
通过 1kHz 分时扫描区分（每行 0.5 ms），因此物理上相邻的键各自独立、互不干扰。

丝印排布（面朝键盘看）：

```
         Col0   Col1   Col2   Col3
Row1 →  KEY4   KEY5   KEY6   KEY7     （上一行）
Row0 →  KEY0   KEY1   KEY2   KEY3     （底行）
```

本次 **8 个键位全部用满**（Row0 四个 + Row1 四个）：

| 按键 | 物理交点 | 行引脚 | 列引脚 | 功能 | 操作方式 |
|------|----------|--------|--------|------|----------|
| **KEY0** | Row0 × Col0 | E10 | E11 | **上一张** | 单次按下 |
| **KEY1** | Row0 × Col1 | E10 | D11 | **下一张** | 单次按下 |
| **KEY2** | Row0 × Col2 | E10 | C11 | **自动轮播 开 / 关** | 单次按下切换 |
| **KEY3** | Row0 × Col3 | E10 | **F10** | **当前参数 −**（亮度或对比度，每档 25%） | 按下步进，长按每 200 ms 连续 |
| **KEY4** | Row1 × Col0 | C10 | E11 | **当前参数 +**（亮度或对比度，每档 25%） | 按下步进，长按每 200 ms 连续 |
| **KEY5** | Row1 × Col1 | C10 | D11 | **应急模式 进入 / 退出** | 单次按下切换 |
| **KEY6** | Row1 × Col2 | C10 | C11 | **短按：音频可视化 开 / 关**<br>**长按 0.8 s：切换「亮度 ↔ 对比度」调节模式** | 短按立即生效；按住满 0.8 s 触发切模式 |
| **KEY7** | Row1 × Col3 | C10 | **F10** | **切换转场方式**（滑动 → 淡入淡出 → 旋转擦除，循环） | 单次按下切换，上电默认滑动 |

> **Col3 = F10 一根列线服务两个键**：Row0 选中时是 KEY3（参数 −），Row1 选中时是 KEY7
> （切转场）。引脚取自核心板原理图 `IO.SchDoc` 的 `Key_Col3` 网络，已确认 F10 在本工程
> 其他功能中未被占用。分时扫描让同一个引脚在不同相位承载不同键，不需要额外引脚。
>
> **KEY3 与 KEY4 物理上不相邻**：参数 − 在底行最右端，参数 + 在上一行最左端，
> 正好是斜对角，两个键都很好按。
>
> **注意**：源码旧注释里 Row1 曾写作 D10，实际约束是 **C10**（以 `sd_hdmi_bmp.adc` 为准）。
>
> **V31 起 KEY3 / KEY4 是「当前参数」键**：上电默认调**亮度**，长按 KEY6 0.8 秒切到**对比度**，
> 再长按一次切回亮度。当前在调哪个参数，看左上角第二行——显示 `BRI 100%` 就是亮度，
> 显示 `CON 100%` 就是对比度。
>
> **V32 起左上角多出第三行**：`SLIDE` = 当前是滑动转场，`FADE` = 当前是淡入淡出。
> 按一下 KEY7 就切换，不用等切图就能从这一行确认。

## 三、逐项功能说明

### KEY0 / KEY1 —— 上一张 / 下一张（转场方式由 KEY7 决定）

- 按下后由 SD 卡读出下一张（或上一张）图片写入另一个帧缓存，写完才切换显示，过程中画面不闪。
- 转场分三种，按 **KEY7** 循环切换（左上角第三行显示当前是哪种）：

**① 滑动转场（`SLIDE`，上电默认）**
- 整帧滚动，**10 行/帧 × 48 帧 ≈ 800 ms**，每帧位移仅屏高 2.1%。
- **KEY1 下一张** → 画面整体向下移动，新图从**顶部**推入
- **KEY0 上一张** → 画面整体向上移动，新图从**底部**推入
- 全程无黑场，是连续滚动，方向与按键语义一致。

**② 淡入淡出（`FADE`）**
- **淡出到黑 → 换图 → 淡入**，各 16 帧，共 **32 帧 ≈ 534 ms**。
- 亮度按 17 档平滑变化（每档 6.25%），全黑只有 1 帧（16.7 ms），换图那一刻看不出来。
- 方向键语义不变：KEY0 仍是上一张、KEY1 仍是下一张，只是不再有位移方向。

**③ 旋转擦除（`ROTATE`，V34）**
- 一条分界线绕屏幕中心**匀速转一整圈**，扫过的扇形区域直接换成新图，
  没扫到的部分仍是旧图 —— 观感是"新图被一条转动的边界擦进来"。
- **48 帧 ≈ 800 ms**，每帧转 7.5°（12 帧一个象限）。
- **方向跟随按键**：KEY1 下一张 = **顺时针**，KEY0 上一张 = **逆时针**。
- 全程只读一个地址流，不闪黑、不叠化；边界按 16 像素一块量化，
  斜边有极轻微的台阶，正常观看距离看不出。

### KEY2 —— 自动轮播

- 按一次开启：每隔 **1 秒**自动切换下一张（滑动方向 = 最近一次手动切图的方向，默认为下滑）。
- 再按一次关闭：停在当前图片。
- 关闭后 KEY0 / KEY1 仍可正常手动切图。

### KEY3 / KEY4 —— 亮度调节

这两个键调的是**当前选中的参数**，参数本身由 KEY6 长按切换（见下）。

**亮度**（`BRI`）
- 范围 **25% ~ 200%**，共 8 档（25 / 50 / 75 / 100 / 125 / 150 / 175 / 200%），默认 100%。
- 整体提亮或压暗，明暗对比关系不变。

**对比度**（`CON`）
- 范围 **50% ~ 200%**，共 7 档（50 / 75 / 100 / 125 / 150 / 175 / 200%），默认 100%。
- 以中灰 128 为支点拉开/压缩明暗差距：调低整幅发灰（像蒙层雾），调高暗部更黑、
  高光更亮，画面"更透"。超过 150% 后两端会开始削顶，属正常现象。
- 数学上 `out = (rgb − 128) × c / 256 + 128`，与亮度合并成
  `out = rgb × k / 256 + offset`（`k = 亮度×对比度/256`）一次算完，不额外占乘法器。

**通用**
- **KEY3 减、KEY4 加**；每按一次步进一档，按住不放每 200 ms 自动再进一档（可快速调到端点）。
- 左上角状态栏第二行实时显示当前参数与数值：`BRI 100%` 或 `CON 120%`——
  **看这一行就知道现在按 KEY3/KEY4 调的是哪个**。
- 只作用于画面，不影响字幕和 OSD 文字（字幕保持常亮清晰）。

### KEY5 —— 应急模式

- 按一次进入：切换到**内置应急画面**（数据直接来自 ROM，绕过 SDRAM 帧缓存），
  同时播放警报音（800 / 600 Hz 方波，每 0.35 s 交替）。
- 应急期间 **KEY0 / KEY1 / KEY2 被锁定**，防止误切图。
- 再按一次退出，回到 TF 卡图片播放。

### KEY6 —— 短按：音频可视化开关 / 长按：切换调节模式

**短按**（不足 0.8 秒就松手）
- 控制画面**右上角 8 段音频频谱**的显示。
- **上电默认开启**。按一次关闭 → VU 表完全消失（连暗底一起消失，画面像素直通）；
  再按一次恢复显示。

**长按**（按住满 0.8 秒）
- 在「调亮度」和「调对比度」之间切换，松手后 KEY3 / KEY4 就作用在新参数上。
- 切换完成的标志：左上角第二行从 `BRI xxx%` 变成 `CON xxx%`（或反过来）。
- 长按只触发一次，继续按住不会反复来回切。

> **为什么短按要等松手才生效**：如果按下就翻转显示，那么长按切模式时会顺带把它关掉。
> 改成松手判定后，正常点按（100~200 ms）松手即生效，手感上没有延迟。

**补充**
- 关闭期间音频照常播放，只是不画柱状图；滤波器的状态一直在跑，重新打开立刻有数据，无需预热。
- 柱高 = 该频段的实时能量，低段绿色 / 中段黄色 / 高段红色。

### 频谱读法（V33 新增）

8 根柱子从左到右对应 **100 / 200 / 400 / 800 / 1600 / 3200 / 6400 / 11000 Hz**，
按倍频程分布，和声学里的倍频程分析仪一致：

| 位置 | 频段 | 典型声源 |
|---|---|---|
| 第 1~2 根 | 100 / 200 Hz | 贝斯、底鼓、男低音基频 |
| 第 3~4 根 | 400 / 800 Hz | 人声主体、吉他中低音 |
| 第 5~6 根 | 1.6k / 3.2k Hz | 人声齿音、弦乐亮度 |
| 第 7~8 根 | 6.4k / 11k Hz | 镲片、齿音、空气感 |

柱高是**对数刻度**（每 2 倍能量升 8 级），所以弱信号也看得见；
低于门限的噪声会直接归零，静音时 8 根柱子全灭。
上升跟手、下降每帧减 3（约 0.45 秒落到底），不会闪成频闪灯。

### KEY7 —— 切换转场方式

- 按一次循环切换 **滑动 `SLIDE` → 淡入淡出 `FADE` → 旋转擦除 `ROTATE` → 滑动…**
- **上电默认滑动**；设置不记忆，重新上电回到滑动。
- 按下瞬间左上角第三行就变，不用等切图确认。
- **只影响之后发生的转场**：正在进行的转场不会被打断，这一次走完后，下一次才用新方式。
- 手动切图（KEY0 / KEY1）和自动轮播（KEY2）都走当前选中的方式。
- 淡变期间右上角 **频谱会暂时隐去**，那一块跟着画面一起变暗；淡变结束自动恢复。
- 旋转擦除期间频谱照常显示（不改变亮度，也就不需要隐去）。

> **为什么淡变是"淡出到黑"而不是两图叠化**：叠化需要同一像素位置上新旧两图同时在读，
> 也就是 SDRAM 要同时开两条读数据流。本板 SDRAM 只有一个读口，帧缓存读是单条顺序流，
> 要做双流得再加一整套读通道 + FIFO + 仲裁，占的资源和时序风险都远超收益。
> 所以用电影电视里同样标准的"淡出 → 换图 → 淡入"，切换动作藏在全黑那一帧里，
> 观感上就是画面暗下去再亮起来。

> **为什么旋转是"擦除"而不是把整幅图转起来**：把画面真的旋转，需要输出像素去源图
> 的旋转坐标处取样（二维重采样），读地址在行内是跳跃的；本工程 SDRAM 是单条顺序
> 读流，一帧只允许在固定位置换一次源帧。要做真旋转必须再加随机读通道 + 行缓存 +
> 后备帧缓存，而当前时序只剩 0.18 ns 余量，风险不可接受。
> 旋转擦除在视觉上同样是"绕中心转"，但每个像素周期仍然只读一个地址 —— 只是把读
> 突发缩到 16 字（16 像素），在块边界上选择读旧帧还是新帧。

## 四、板载指示

### 8 个 LED（高电平点亮）

| LED | 含义 | 正常状态 |
|-----|------|----------|
| led0 | 图片已显示（`display_valid`） | 出图后常亮 |
| led1 | SDRAM 初始化完成 | 常亮 |
| led2 | 系统 PLL 锁定（`clk_pll_lock`） | 常亮 |
| led3 | 视频 PLL 锁定（`video_pll_lock`） | 常亮 |
| led4 | TF 卡中找到 WAV 音频 | 有音频文件时亮 |
| led5 | WAV 正在播放 | 播放期间亮 / 闪烁 |
| led6 | SD 卡初始化完成 | 常亮 |
| led7 | SD 状态机最低位（`state_code[0]`） | 工作中快速变化 |

### 4 位数码管

- **开机前 2 秒**：最右两位显示版本号 **`34`**，用于确认烧录的是 V34 版。
- **2 秒后**：最右一位显示 SD 卡状态机状态码：

| 状态码 | 含义 |
|--------|------|
| 0 | 空闲（等待按键 / 稳定显示中） |
| 1 | 扫描 TF 卡寻找 BMP |
| 2 | 正在解析 BMP 文件头 |
| 3 | 等待写入帧缓存 |
| 4 | 正在读取像素数据（大文件时会停留较久，属正常） |

## 五、TF 卡内容要求

| 项目 | 要求 |
|------|------|
| 图片格式 | **BMP，24 位，无压缩**（32 位带 Alpha、8 位索引色、PNG/JPG 均不支持） |
| 图片尺寸 | **640×480** 或 **1280×960**（二者为整数 2 倍关系，1280×960 由 2×2 块抽取到 640×480） |
| 图片数量 | 开机扫描前 4 张 BMP |
| 显示位置 | 两种尺寸都**整幅铺满**屏幕（同为 4:3，比例不失真） |
| 左上角 | 常显图片真实分辨率 `640x480` / `1280x960` 与亮度 |
| 音频 | WAV，**48 kHz / 16 bit / 双声道**，播完自动循环 |

> 其他尺寸（如 800×600、1920×1080）会被跳过视作"无此文件"，程序继续找下一张。

## 六、上板自检顺序

1. 拨 SW0 复位 → 数码管应显示 **`34`**（2 秒），led1/2/3/6 应亮。
2. 2 秒后数码管跳到 `1` 或 `2`，随后应出现第一张图片，led0 亮。
   左上角应有三行：`640x480` / `BRI 100%` / **`SLIDE`**。
3. 按 **KEY1** → 画面整体**向下**滚动，新图从顶部进入。
4. 按 **KEY0** → 画面整体**向上**滚动，新图从底部进入。
5. 按 **KEY7** → 左上角第三行变成 **`FADE`**；再按 **KEY1** →
   画面先**暗下去到全黑**，再**亮起来**变成新图（约 0.5 秒），过程中右上角频谱会暂时隐去。
5b. 再按 **KEY7** → 左上角第三行变成 **`ROTATE`**；按 **KEY1** →
    一条分界线从 12 点方向**顺时针**转一圈（约 0.8 秒），新图随扫过的扇区进入；
    按 **KEY0** 则**逆时针**转。再按 **KEY7** 回到 `SLIDE`。
6. 按 **KEY2** → 每秒自动切一张（用当前选中的转场方式）；再按一次停止。
7. 按 **KEY3** → 画面**变暗**，左上角第二行变成 `BRI xxx%`；按 **KEY4** → 变亮。
8. 长按 **KEY6** 1 秒 → 左上角第二行从 `BRI` 变成 **`CON`**，此时 KEY3/KEY4 调对比度。
9. 短按 **KEY6** → 右上角频谱**消失**；再按 → **恢复**。
9b. **频谱验证**：放一首有鼓和贝斯的歌，第 1~3 根柱子应明显跟着鼓点跳；
    换一首纯人声，第 4~6 根应主导。若 8 根柱子总是同涨同落（像以前那样），
    说明烧的是 V32 的旧版。
10. 按 **KEY5** → 切到应急画面并响警报；再按退出。应急期间 KEY0/1/2 无响应（正常）。
11. 插耳机或接带音箱的显示器 → 应能听到 TF 卡中的 WAV。

> **V34 重点验证**：第 1 步数码管显示 `34`、第 5 步的淡变、第 5b 步的旋转擦除
> （KEY7 连按两次到 `ROTATE`，KEY1 顺时针 / KEY0 逆时针）。
> 若第 5b 步第三行始终停在 `FADE`，说明烧的是 V33 或更早的 bit；
> 若旋转方向与按键相反，检查 `slide_dir_sd` 的赋值方向。

## 七、若滑动方向与预期相反

当前定义为「下一张 = 画面下移 / 新图从顶部进」。若希望反过来，
只需把 `top.v` 中 `slide_dir_sd` 的两行赋值互换：

```verilog
if      (k1_s2 & ~k1_s1) slide_dir_sd <= 1'b0;   // KEY1 改为上滑
else if (k0_s2 & ~k0_s1) slide_dir_sd <= 1'b1;   // KEY0 改为下滑
```

滑动速度由 `trans_fade` 的参数 `STEP_ROWS` 决定：`40` = 12 帧（约 200 ms），
调大更快、调小更慢（建议取 480 的约数：24 / 30 / 40 / 48 / 60 / 80）。
